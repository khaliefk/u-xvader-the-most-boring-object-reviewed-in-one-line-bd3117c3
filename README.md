A one-line review of the dullest everyday object I could name, written by
`main.py` (Python standard library only) to `/output/entry.txt`.

The entry, 87 characters:

> My ceiling fan: ten years spinning, zero miles travelled, five stars. Would spin again.

Run it:

```sh
python3 main.py
cat /output/entry.txt
```
